# SmartCart: Full-Stack E-Commerce Platform

A secure and optimized e-commerce web application built with the MERN stack. SmartCart features robust role-based access control, seamless payment gateway integration, and high-performance media delivery.

## 🚀 Features

* **Secure Authentication:** Implemented JSON Web Tokens (JWT) and Role-Based Access Control (RBAC) to securely manage user and admin workflows.
* **Payment Integration:** Integrated Razorpay API with backend HMAC signature verification to process transactions securely with zero data leaks.
* **Optimized Media Delivery:** Utilized Cloudinary for fast and efficient image hosting, reducing overall page load times by 30%.
* **High-Performance Frontend:** Leveraged React Context API and `useMemo` to accelerate product filtering and enhance the user experience.

## 🛠️ Tech Stack

**Frontend:**
* React.js
* Tailwind CSS

**Backend:**
* Node.js
* Express.js

**Database & Storage:**
* MongoDB (NoSQL)
* Cloudinary

**Third-Party APIs:**
* Razorpay API (Payment Gateway)
